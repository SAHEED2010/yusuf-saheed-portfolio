# Domain Docs

This is a single-context repository. Before exploring or changing the portfolio, read `CONTEXT.md` and any ADRs under `docs/adr/` that touch the current work.

Use the glossary's canonical terms in specs, tickets, explanations, and tests. If a term is missing or overloaded, resolve it before implementation and update `CONTEXT.md`.

ADRs are reserved for decisions that are hard to reverse, surprising without context, and the result of a real trade-off. Do not use `CONTEXT.md` as a spec or implementation scratchpad.
